About TinyGuard

TinyGuard is a digital safety platform designed to help protect children online by detecting harmful and inappropriate language in uploaded text files. The project focuses on creating a safer online environment for families through secure account systems, file scanning, and parent-child connections.

Frontend

The frontend of TinyGuard was developed using HTML, CSS, and JavaScript to create a responsive and user-friendly interface for both parents and children. The frontend includes features such as account registration, login functionality, file uploads, and profile management. Users can upload text files directly through the website, while the interface dynamically updates depending on whether the user is logged in or not. The design was built to work across desktop, tablet, and mobile devices while maintaining a clean and secure user experience.

Backend

The backend of TinyGuard was built using Node.js and Express. It handles the server-side logic, authentication, API routes, and communication between the frontend and database. The backend processes user login and registration requests, securely hashes passwords using bcrypt, and protects routes through authentication middleware. It also handles text file scanning using the Aho-Corasick search algorithm to detect harmful or inappropriate words efficiently. In addition, the backend manages parent-child account connections and communication with the PostgreSQL database.

Database

TinyGuard uses PostgreSQL as its database system to securely store user information, account roles, and parent-child relationships. The database structure was designed using relational tables and role-based connections to support secure authentication and account management. User passwords are stored as hashed values for improved security, and the database is connected to the backend through environment variables and a PostgreSQL connection string. PostgreSQL was chosen because of its reliability, structured relational design, and strong support for secure data handling.
